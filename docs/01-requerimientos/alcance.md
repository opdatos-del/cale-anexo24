# Alcance del sistema

## Objetivo

Desarrollar una aplicación web para el control automatizado de inventarios de comercio exterior conforme al Anexo 24, para PROCESADORA DE ALIMENTOS CALE, S.A. de C.V., durante septiembre-diciembre de 2026. La solución moderniza la interfaz observada e integra Módulo C sin modificar su estructura sin autorización.

## Entregables funcionales

- Seguridad por usuarios, perfiles y actividades; revisión de mínimo privilegio.
- Consulta de datos generales, materiales, productos, estructuras, entradas, salidas, materiales utilizados, activo fijo y saldos.
- Reportes, filtros y exportación con errores accionables.
- Carga XLS/XLSX validada con vista previa, detalle por fila y registro transaccional.
- Bitácora consultable de operaciones críticas.

## Límites

No incluye migración o modificación no autorizada de Módulo C, automatización directa de trámites SAT, aplicación móvil ni integraciones externas no evidenciadas. El inventario físico de base y la plantilla oficial se incorporan mediante acceso y artefactos autorizados, sin inventar su contenido.
