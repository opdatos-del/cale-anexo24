# Despliegue

1. Aprobar versión, evidencia de pruebas y ventana de cambio.
2. Respaldar configuración y validar conectividad autorizada a Módulo C.
3. Desplegar API y frontend versionados en el ambiente objetivo.
4. Aplicar secretos/configuración por ambiente y ejecutar verificación de salud.
5. Probar inicio de sesión, permiso, consulta y bitácora con cuenta de prueba.
6. Registrar versión, hora, responsable y resultado.

## Reversión

Detener la promoción, restaurar el artefacto previamente aprobado y su configuración compatible, validar salud y documentar el incidente. No se ejecutan cambios estructurales en Módulo C como parte de la reversión.
