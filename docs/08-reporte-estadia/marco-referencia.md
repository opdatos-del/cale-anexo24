# Marco de referencia

La referencia funcional es la auditoría de Anexo 24 realizada el 03 de
septiembre de 2026 y su consolidación posterior por fases. El contexto
tecnológico considera Angular, Java 21, Spring Boot, Spring Security y SQL
Server. El contexto de negocio contempla el control automatizado de inventarios
de comercio exterior asociado al Anexo 24 y la operación de PROCESADORA DE
ALIMENTOS CALE, S.A. de C.V.

Referencias internas que gobiernan el proyecto:

- `docs/01-requerimientos/matriz-paridad-legacy-v1.md` — cobertura por
  capacidad con estados y evidencia.
- `docs/01-requerimientos/decisiones-alcance-v1.md` — paquete ejecutivo de
  decisiones pendientes.
- `docs/05-pruebas/v1-technical-closure.md` — snapshot de cierre técnico V1.
- `docs/05-pruebas/auditoria-funcional-e2e-v1.md` — auditoría E2E de la
  aplicación completa.
- `docs/08-reporte-estadia/evidencias-proyecto.md` — cronología de fases con
  problema, método, resultado y limitación.
