# Antecedentes

PROCESADORA DE ALIMENTOS CALE utiliza un sistema Anexo 24 visible en versión 1.0.1.0, basado observablemente en ASP.NET Web Forms. La auditoría detectó catálogos, operaciones, reportes, gestión de permisos y carga de facturación, además de oportunidades en seguridad, mensajes de error y experiencia de carga. La modernización plantea Angular, Spring Boot y una integración controlada con SQL Server Módulo C.
