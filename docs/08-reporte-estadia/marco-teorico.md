# Marco teórico

La arquitectura por capas separa presentación, aplicación, dominio e infraestructura para reducir acoplamiento. Las API REST ofrecen contratos HTTP/JSON y la autenticación/autorización protegen recursos mediante identidades y permisos. Las pruebas unitarias, de integración y funcionales proporcionan evidencia complementaria. La trazabilidad registra eventos relevantes para auditoría y soporte; el principio de mínimo privilegio limita cada cuenta a las acciones indispensables.
