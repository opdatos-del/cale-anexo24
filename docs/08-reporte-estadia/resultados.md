# Resultados

Se obtuvo una línea base funcional verificable: 1,109 materiales, 2,630 productos, ~4,981 relaciones de estructuras en consulta amplia, 52 actividades y dos perfiles visibles. Se documentaron cinco reportes con error reproducible y un proceso de carga que rechaza archivos inválidos sin detalle. A partir de la evidencia se definió una solución modular con controles de seguridad, trazabilidad, validación y propuesta de datos complementaria.
