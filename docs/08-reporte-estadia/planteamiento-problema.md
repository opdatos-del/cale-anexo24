# Planteamiento del problema

El sistema de referencia concentra funciones relevantes para Anexo 24, pero presenta riesgos observables: exposición de contraseña en interfaz, permisos administrativos amplios, reportes con error genérico y carga de facturación sin guía ni diagnóstico detallado. La falta de separación moderna y trazabilidad técnica dificulta mantenimiento y soporte. Se requiere una solución web segura, verificable e integrada con la información existente.
