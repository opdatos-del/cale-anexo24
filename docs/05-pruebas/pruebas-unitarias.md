# Pruebas unitarias

| ID | Componente | Resultado esperado |
|---|---|---|
| PU-001 | Validador de rango | Rechaza fechas ausentes, invertidas o fuera de política. |
| PU-002 | Validador de contraseña | Exige política configurada y nunca devuelve el valor. |
| PU-003 | Autorizador | Permite solo la actividad asignada. |
| PU-004 | Validador de plantilla | Detecta extensión, columnas, tipos y valores requeridos. |
| PU-005 | Servicio de bitácora | Omite secretos y conserva usuario, acción, fecha y correlación. |
